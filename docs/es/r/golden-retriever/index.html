Cómo jugar

El primer sorteo es gratuito e incluye 1 repetición. Las repeticiones excluyen el resultado actual y tienen probabilidades distintas de las iniciales.

Las probabilidades usan pesos creados para el juego, no proporciones mundiales de razas ni predicciones de ascendencia, destino o temperamento. Al repetir, se excluye el resultado actual y cambia la probabilidad.
